系统采用典型的 SSM 三层架构，各类之间的依赖关系如图 1-3 所示：Controller 表现层接收 HTTP 请求并调用 Service 业务层；Service 层以"接口 + 实现类"方式组织，实现类标注 @Service 并由 Spring 容器管理，通过 @Transactional 实现声明式事务；Mapper 持久层为 MyBatis 接口，与 resources/mapper 下的 XML 映射文件对应，由 SqlSessionFactory 生成代理对象注入 Service；Entity 实体层与数据库表一一对应，在各层之间传递数据。各层只依赖下一层的接口，层与层之间通过 Spring IoC 解耦，便于维护和单元测试。
